# 📚 Bookstore API

A simple **Spring Boot REST API** for managing books.  
Built as a learning project to understand **Spring Boot**, **Spring Data JPA**, and **PostgreSQL** integration.

---

## ⚙️ Tech Stack

- **Java 17**
- **Spring Boot 3**
- **Spring Web**
- **Spring Data JPA**
- **PostgreSQL**
- **Maven**
- **Swagger UI** (API Documentation)

---

## 🚀 Features

- Add new books
- View all books
- Fetch a single book by ID
- Update book details
- Delete a book
- Integrated Swagger UI for easy testing
